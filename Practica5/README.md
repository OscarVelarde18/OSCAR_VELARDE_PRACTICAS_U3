# Práctica 5 – Macros

**Archivo:** `main.asm`

## Qué hace
Define dos macros: `MostrarMensaje` (imprime una cadena con salto de línea) y `Multi` (multiplica dos números e imprime el resultado). Las usa en `main` para mostrar un saludo, una despedida y el producto de 4 × 5. Las macros se expanden en el código en lugar de saltar a ellas.

## Qué comprobé al ejecutarlo
- Que aparece `Bienvenido al sistema`, `Nos vemos!` y `+20`.
- Que llamar a una macro varias veces con distintos argumentos funciona.
